# Solucao Paliativa - Dor 03

## Proposta
Motor de verificacao e relatorio de divergencias, sem alterar os sistemas de origem.

## Requisitos
- Operacao inicial em somente leitura.
- Dados sinteticos ate autorizacao de acesso.
- Relatorio de excecoes e evidencias.
- Reprocessamento controlado.
- Sem correcao automatica no ERP.

## Limitacao
Nao substitui ajustes e integracoes na origem.
