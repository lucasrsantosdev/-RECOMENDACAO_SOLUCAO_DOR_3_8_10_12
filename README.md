# FOURD VITRU - POCs 03, 08, 10 e 12

## Objetivo
Investigar e demonstrar solucoes para quatro dores
academicas, financeiras e cadastrais da Vitru.

## POCs
- Dor 03: Conciliacao Academica e Financeira
- Dor 08: Conciliacao NDD e Faturamento
- Dor 10: Governanca Financeira FIES
- Dor 12: Qualidade Cadastral e Enderecos

## Metodologia
Diagnostico -> Hipoteses -> Causas-raiz ->
Evidencias -> Solucao paliativa ->
Solucao definitiva -> Testes -> Homologacao.

## Estrutura
Cada POC possui documentacao, propostas de solucao,
codigo-fonte, dados sinteticos e testes.

## Situacao
Bootstrap documental.
Motores de processamento ainda nao implementados.
Fontes e regras reais pendentes de homologacao.

## Seguranca
Proibido incluir dados pessoais e evidencias reais
no repositorio sem revisao e autorizacao.
